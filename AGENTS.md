## Project

Expo 55 + React Native 0.83. **Android-only** (no iOS/web). File-based routing via `expo-router`.

- **State:** Zustand stores in `src/stores/`. Use individual selectors (`useStore(s => s.field)`) — never full store subscription.
- **Imports:** `@/*` maps to `./src/*`
- **Styling:** NativeWind v5 + Tailwind CSS v4. `global.css` entry: `@import "tailwindcss"; @import "nativewind/theme";`
- **TypeScript:** strict, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `forceConsistentCasingInFileNames`

## CI/CD Gotchas

- `android/` not tracked — generated by `npx expo prebuild --platform android`
- `setup-android@v3` no longer accepts `api-level` or `build-tools`
- `react-native-worklets` required peer of `react-native-reanimated` 4.x
- EAS prod build: `buildType: "apk"`, `ndk: "27.1.12297006"`
- Keystore decoded from `ANDROID_KEYSTORE_BASE64`
- Version: `package.json` + `app.json` (`expo.version` + `expo.android.versionCode`)
